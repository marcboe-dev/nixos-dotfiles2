# NordVPN – Kurzbefehle

## Anmeldung

```bash
nordvpn login
```

## Verbindung herstellen

```bash
# Mit dem schnellsten verfügbaren Server verbinden
nordvpn connect

# Mit einem bestimmten Land verbinden
nordvpn connect Austria
```

## Verbindung trennen

```bash
nordvpn disconnect
```

## Status prüfen

```bash
nordvpn status
```

## Grafische Oberfläche

```bash
nordvpn-gui
```

## Dienst verwalten

Status anzeigen
```bash
systemctl status nordvpnd.service
``
``
# Dienst starten
sudo systemctl start nordvpnd.service
```

## Hilfe

```bash
nordvpn help
```
